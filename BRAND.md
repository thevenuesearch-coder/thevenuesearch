# Venue Search visual refresh

The interface has been refreshed around the `VS / Venue Search` identity shown in the supplied Venue Search documents.

## Visual direction
- Deep burgundy / wine for the primary brand tone
- Antique gold for highlights, dividers and premium actions
- Warm cream / parchment surfaces
- Soft rose accents
- Serif editorial headings paired with a clean sans-serif UI

The logo is implemented as a lightweight SVG in `public/venue-search-logo.svg` so it stays crisp on mobile and desktop.
